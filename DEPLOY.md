# Despliegue

Esta guía quedó desactualizada (se escribió antes de Inventario,
Producción y el Dashboard Gerencial, y antes de tener datos reales
cargados). Las instrucciones vigentes para instalar, configurar variables
de entorno y publicar en **Netlify** están en **[`README.md`](./README.md)**.

Lo único que sigue siendo válido de esta guía: si alguna vez necesitás
crear un proyecto de Supabase **nuevo** desde cero, `schema.sql` (en la
raíz de este proyecto) crea todas las tablas, activa Row Level Security y
suma las tablas a Realtime — pero tu proyecto de Supabase **actual** ya
tiene todo esto y tus datos reales, así que no hace falta volver a
ejecutarlo.
